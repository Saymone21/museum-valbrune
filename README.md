## Lancer le projet

Expliquez comment ouvrir le site en local (extension utilisée, etc.).
Pour lancer le projet : 
- Lancer VSCode,
- Télécharger l'extension Live Server,
- Ouvrir le dossier contenant le projet,
- Ouvrir le fichier index.html,
- Faire un clic droit sur la fenetre de code,
- Cliquer sur "Open with Live Server"
